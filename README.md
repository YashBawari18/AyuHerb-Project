# Ayurvedic Herb Traceability System

A blockchain-based system to track Ayurvedic herbs from farm to consumer.

## What this system does:
1. **Farmers/Collectors** record where they picked herbs (with GPS location)
2. **Processors** add quality test results 
3. **Manufacturers** create final products with QR codes
4. **Consumers** scan QR codes to see the complete journey

## Project Structure:
- `blockchain-network/` - The blockchain setup
- `chaincode/` - Smart contracts (rules for the blockchain)
- `api/` - Server that connects everything
- `frontend/` - Web pages for users
- `dashboard/` - Admin control panel
