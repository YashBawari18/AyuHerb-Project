# 🎯 HACKATHON DEMO SCRIPT

## 🌟 **Your Project: Ayurvedic Herb Traceability System**

### **Problem Solved:**
- Lack of transparency in Ayurvedic herb supply chains
- No way to verify herb authenticity and quality
- Difficulty tracking from farm to consumer
- No immutable record of collection and processing

### **Your Solution:**
Complete blockchain-based traceability system with:
✅ GPS-tagged collection recording
✅ Quality testing validation  
✅ Processing step tracking
✅ QR code generation for consumers
✅ Real-time blockchain verification

---

## 🎬 **5-MINUTE DEMO FLOW**

### **1. Homepage Overview (30 seconds)**
- Show `http://localhost:3000`
- Explain the 4 main portals
- Show blockchain status (live blocks/herbs)

### **2. Farmer Collection (1 minute)**
- Go to `/collect`
- Fill out Ashwagandha collection form
- Show GPS location capture
- **Record the Event ID!**
- Explain immutable blockchain storage

### **3. Lab Quality Testing (1 minute)**
- Go to `/process` → Quality Testing tab
- Use Event ID from step 2
- Add pesticide/purity test results
- Show Pass/Fail validation
- Explain compliance automation

### **4. Processing & QR Generation (1 minute)**
- Processing tab: Add drying/grinding steps
- QR Generation tab: Create final product QR
- Show generated QR code
- Explain consumer-facing verification

### **5. Consumer Verification (1.5 minutes)**
- Go to `/verify`
- Enter Event ID or "scan" QR
- **Show complete traceability timeline:**
  - 🌱 Farm collection (GPS location)
  - 🧪 Lab test results 
  - ⚙️ Processing steps
  - 📦 Final product info

### **6. Admin Dashboard (30 seconds)**
- Go to `/dashboard`
- Show blockchain network stats
- Recent activity monitoring
- Real-time analytics
